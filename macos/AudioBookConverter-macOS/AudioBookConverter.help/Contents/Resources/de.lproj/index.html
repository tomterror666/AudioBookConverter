AudioBookConverter

AudioBookConverter ist eine macOS-App, die einen Ordner mit MP3-Dateien in eine einzelne Hörbuchdatei umwandelt.

Die App basiert auf React Native für macOS und enthält eine Konvertierungs-Pipeline, die:

  • MP3-Titel einlesen und Kapitelgrenzen erkennen kann,
  • alle Titel zu einer Audiodatei mit Kapitel-Metadaten zusammenführen kann,
  • eine fertige Hörbuchdatei (.m4b) erzeugen kann.

Plattform

Dieses Projekt ist derzeit auf macOS ausgerichtet.

Die Python-Einstiegspunkte für die Konvertierung (whisper_chapter_scan.py, merge_mp3_chapters.py im Ordner scripts/ im Repository) werden beim Erstellen des macOS-Ziels im App-Bundle mitgeliefert, sodass eine Release-App auch ohne eine lokale Repository-Kopie läuft. Der native Code greift außerdem auf den Ordner scripts/ neben einem lokalen Checkout zurück, wenn AUDIOBOOK_PROJECT_ROOT gültig ist (üblich bei der Entwicklung direkt aus dem Repository).

Voraussetzungen

Bevor Sie die App starten, sollten folgende Abhängigkeiten verfügbar sein:

  • Node.js 18 oder neuer
  • npm
  • Xcode (mindestens einmal geöffnet)
  • CocoaPods
  • ffmpeg und ffprobe im PATH
  • Python 3

Für die volle Konvertierungsfunktionalität legen Sie eine Python-Virtualumgebung unter ~/.audioBookConverter (in Ihrem Benutzerverzeichnis) an und installieren Sie die benötigten Pakete (z. B. faster-whisper). Die App nutzt diesen Pfad für alle Builds; alternativ können Sie im integrierten Python-Abhängigkeitsbereich Installieren verwenden, um die Umgebung anzulegen.

Google-Books-API-Schlüssel (optional). Die App kann anhand des ausgewählten Ordnernamens ein Buchcover über die Google-Books-API suchen. Dazu können Sie GOOGLE_BOOKS_API_KEY in einer lokalen .env-Datei setzen (siehe .env.example im Repository-Root; nach .env kopieren und den Schlüssel eintragen). Diese Datei wird nicht von Git versioniert. Ohne Schlüssel funktioniert unauthentisierter Zugriff weiterhin, allerdings mit strengeren Ratenbegrenzungen. Ein Schlüssel ist nur eine Erleichterung und für den übrigen Konvertierungsablauf nicht erforderlich.

Erste Schritte (Entwicklung)

1) JavaScript-Abhängigkeiten installieren

npm install

2) macOS-Pods installieren

cd macos
pod install
cd ..

3) Metro starten

Terminal 1:

npm start

4) macOS-App starten

Terminal 2:

npx react-native run-macos

Bedienung

  1. App starten.
  2. Den Ordner mit Ihren MP3-Dateien auswählen.
  3. Die Konvertierungs-Pipeline über die Benutzeroberfläche starten.
  4. Warten, bis die Verarbeitung abgeschlossen ist.

Erwartete Ausgabedateien im gewählten Projekt-/Ausgabeordner:

  • AudiobookConverter_kapitel.log
  • AudiobookConverter_merged.m4a (Zwischendatei)
  • AudiobookConverter.m4b (fertiges Hörbuch)

Fehlerbehebung

  • Bei nativen Build-Fehlern erneut pod install im Ordner macos/ ausführen.
  • Bei Problemen mit dem Xcode-Build-Cache: Produkt → Build-Ordner bereinigen.
  • Wenn Abhängigkeitsprüfungen in der App fehlschlagen: ffmpeg, Python und die Virtualumgebung ~/.audioBookConverter prüfen.
  • Wenn Sie zuvor einen Ordner .audioBookConverter innerhalb eines Repository-Klons verwendet haben, verschieben Sie ihn nach ~/.audioBookConverter (oder entfernen Sie ihn und nutzen Sie Installieren im Python-Bereich der App, um die Umgebung dort neu anzulegen).
